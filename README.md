# PentAiA v2

PentAiA v2 is an AI-assisted penetration-testing research and learning project built with LangChain, LangGraph, Google Gemini, and a remote Kali Linux execution environment.

## Current Phase

Phase 1 — End-to-end Nmap demonstration.

## Initial Architecture

User → LangGraph → Gemini/LangChain → Security Tool Wrapper → Kali Executor → SSH → Kali Linux → Authorized Lab Target
